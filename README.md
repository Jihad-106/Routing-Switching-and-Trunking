# Routing, Switching & Trunking Lab

## 📌 Overview

This project is a Cisco Packet Tracer lab focused on the fundamentals of **Routing, Switching, VLANs, and Trunking**.

The lab demonstrates how multiple VLANs communicate through a **Layer 3 Multilayer Switch**, how access and trunk ports are configured, and how inter-VLAN communication works.

---

## 🎯 Lab Objectives

- Configure VLANs
- Assign switch ports to VLANs
- Configure Access Ports
- Configure Trunk Ports using IEEE 802.1Q
- Configure a Multilayer Switch for Layer 3 Routing
- Configure Switch Virtual Interfaces (SVIs)
- Enable Inter-VLAN Routing
- Configure DHCP Relay
- Configure a Server VLAN
- Configure DHCP and DNS Services
- Verify network connectivity using ping and show commands
